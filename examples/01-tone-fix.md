# 案例：一条差点发出去的消息

## 背景

设计师小李的方案被研发驳回三次。第四次沟通时，他写好了这样一段话，准备发到项目群里：

```
这个我之前说过了，你自己看需求文档吧。
这不是我负责的，你们部门的问题你们自己解决。
我早就提醒过了，现在出事了吧，呵呵。
行吧，你开心就好，我随便。
我尽快看看，应该没问题。
大家确认一下，相关同学尽快跟进。
马上就要，我不管，反正今天必须给我。
```

## 脚本诊断（实测）

```
$ python scripts/scan_tone.py message.txt --explain

风险分：100/100    高概率被读成敌意：建议整段重写
命中 15 句：高危 11 · 中危 4 · 提醒 0   （101 个汉字）
```

逐句拆开看，最致命的是这三句：

### 「这个我之前说过了」→ 高危

对方的读法：**你在撇清责任，暗示是我的错。**

问题在于：即使这是事实，这句话的功能也不是「说明情况」，而是「划清界限」。群里十几个人看着，对方只会记住自己被当众指出错了。

### 「呵呵」→ 高危

对方的读法：**我在鄙视你。**

「呵呵」在中文职场语境里几乎没有中性用法。这是纯情绪输出，且会永久留在聊天记录里。

### 「我不管，反正今天必须给我」→ 高危

对方的读法：**我不讲理。**

这句话的问题不是态度，是它**关闭了协商空间**。对方要么硬顶，要么阳奉阴违，没有第三种可能。

## 真正的问题不是语气

小李真实的需求是：**方案要改，而且要今天改完。**

但这段话里，只有 0% 的信息在推进这件事：

| 他说的 | 实际功能 |
| --- | --- |
| 我之前说过了 | 证明我没错 |
| 这不是我负责的 | 撇清责任 |
| 我早就提醒过了 | 证明我有先见之明 |
| 呵呵 / 你开心就好 | 表达不满 |
| 我尽快看看 | 没有承诺 |
| 大家确认一下 | 没有责任人 |
| 今天必须给我 | 命令，但没有理由 |

七句话里，六句在**处理情绪**，只有最后一句在**提要求**——而那句要求没有任何支撑。

## 改写版

保留全部原始诉求（方案要改、今天要改完），但换成「事实 + 影响 + 请求 + 时间」：

```
关于方案第四次被驳回这件事，我想先把事实对齐一下：
文档第 3 节写的是「按钮点击后 200ms 内给出反馈」，这版实现是 800ms，
测试环境可以复现（附录屏）。

我这边的排期卡在这上面：视觉稿已经定了，实现不改的话上线要延后，
而 11/3 是市场部的活动日。

我的建议是两个选项：
A. 今天下班前把响应时间改到 200ms 内（我理解是加个 loading 态就够，可以一起看）
B. 如果技术上要多花时间，我们今天下午 3 点拉 15 分钟，把标准改成可实现的数字

@张工 这块是你判断，今天 17:00 前能给个方向吗？
@王产品 需求侧如果同意改成 B，麻烦在文档里同步一下。
```

## 改动对照

| 原句 | 改写 | 为什么 |
| --- | --- | --- |
| 这个我之前说过了 | 「文档第 3 节写的是…，测试环境可以复现」 | 从「我说过」变成「事实在这里」，可核实，不需争辩 |
| 你自己看需求文档 | 「文档第 3 节…（附录屏）」 | 直接给到内容，而不是让他自己找 |
| 这不是我负责的 | 「我这边的排期卡在这上面」 | 从撇清变成说明影响 |
| 你们部门的问题 | 「@张工 这块是你判断」 | 点名到人，不说部门 |
| 我早就提醒过了 | 删掉 | 对推进事情零贡献，只增加敌意 |
| 呵呵 / 你开心就好 | 删掉 | 纯情绪，无法被回应 |
| 我尽快看看 | 「今天 17:00 前能给个方向吗」 | 具体时间 + 具体动作 |
| 大家确认一下 | 「@张工…@王产品…」 | 具名到人 |
| 今天必须给我 | 「今天 17:00 前能给个方向吗」 | 从命令变成请求 + 给了理由 |

## 重跑验证

```
$ python scripts/scan_tone.py fixed.txt

风险分：0/100    基本安全：检查有无模糊承诺即可
命中 0 句：高危 0 · 中危 0 · 提醒 0   （312 个汉字）
```

## 字数从 101 涨到 312，为什么反而更好

因为多出来的 200 字全是**信息**：

- 具体标准（200ms vs 800ms）
- 可复现的证据（测试环境 + 录屏）
- 影响（11/3 活动日）
- 两个可选方案（A / B）及其代价
- 具名的责任人
- 具体时间点

**原版 101 字里，99 个字在表达情绪；改版 312 字里，每一句都在推进决策。**

## 这个案例说明了什么

1. **职场冲突的根源通常不是态度，是信息不足。** 说清事实、影响、选项，情绪自然就没那么重了。
2. **「我之前说过」是最贵的三个字。** 它的收益是「我对了」，成本是「多了一个敌人」。
3. **命令句的本质是关闭协商。** 换成「能不能 + 具体时间」不会削弱强度，反而更容易拿到结果。
4. **具名替代「大家」。** 一条消息 @ 两个人，比十条「相关同学跟进」有用。

## 但有一件事脚本做不到

如果小李和研发已经积累了三个月的矛盾，这段话改得再好也只是缓解。真正的解法可能是：

- 找一次不在群里的、一对一的沟通
- 请上级介入定义标准（而不是让两个人在群里互相证明）
- 或者承认这个协作模式不成立，调整项目结构

**语气检测只能救「一时说错话」，救不了「关系已经坏了」。**
