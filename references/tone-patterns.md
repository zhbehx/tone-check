# 语气风险模式库

每条：**原句 → 对方的读法 → 改写**。

## 一、甩锅型（最容易得罪人）

| 原句 | 对方的读法 | 改写 |
| --- | --- | --- |
| 这个我之前说过了 | 你怎么这么笨 / 我在撇清 | 可能我没说清楚，我再确认一遍：{具体内容} |
| 这不是我负责的 | 别找我 / 我不帮你 | 这块目前是 {X} 在跟，我把他拉进来 |
| 你自己看需求文档 | 自己去找，别烦我 | 需求在文档第 3 节，具体是这段话：{引用} |
| 我早就提醒过了 | 现在出事了你活该 | 之前提过这个风险点，现在看确实发生了，我们看怎么补 |
| 你按我说的做不就行了 | 你不听我的才出事 | 我们当时的方案是 {X}，现在的结果是 {Y}，差在哪我们对一下 |
| 这是你们部门的问题 | 我们不是一伙的 | 这事卡在 {A} 和 {B} 的接口上，两边一起看下 |
| 我已经发邮件了 | 我尽到义务了，剩下不关我事 | 邮件里约了 {X}，目前还没回复，我下午再催一次 |

**共同点**：都在强调「我没错」。职场里最贵的三个字就是「我没错」——因为它必然意味着「是你错」。

## 二、被动攻击型

| 原句 | 对方的读法 | 改写 |
| --- | --- | --- |
| 呵呵 | 我在鄙视你 | （删掉，什么都别加） |
| 随便 / 都行 | 我有意见但不说 | 我倾向 A，因为 {理由}；B 也可以，你定 |
| 你开心就好 | 你会后悔的 | 我担心的是 {具体风险}，如果没问题我就按你的来 |
| 行吧 | 我不情愿 | 可以，那我按这个推进，{时间} 给结果 |
| 好的呢~ | 阴阳怪气 | 好的，{时间} 完成 |
| 你觉得合适吗 | 我觉得不合适 | 我有个顾虑：{具体点}，要不要再确认一下 |
| 没事，我自己弄 | 你欠我的 | 这次我来，下次这块提前一天给我可以吗 |

**共同点**：**有情绪但不直说**。被动攻击的成本最高——因为你既没解决问题，又让对方感到敌意。

## 三、模糊承诺型（最容易被追责）

| 原句 | 对方的读法 | 改写 |
| --- | --- | --- |
| 尽快 | 我不知道什么时候，也不会催你 | 今天 18:00 前给你初版 |
| 我看看 | 我可能会忘 | 我下午看完，17:00 前回复你结论 |
| 回头聊 | 我不想聊 | 明天上午 10 点我们 15 分钟对一下？ |
| 应该没问题 | 有问题我不负责 | 目前看没问题，唯一风险是 {X}，我周三确认后告诉你 |
| 在做了 | 别催了 | 已完成 {A}，还剩 {B}，{时间} 交付 |
| 有进展我同步 | 别指望我主动说 | 每周三我在群里同步一次进度 |
| 我尽量 | 大概率不行 | 能做，但需要 {X}；如果 {X} 没有，就做不了 |

**共同点**：给对方的是**希望**而不是**信息**。一个「尽快」能让对方等三天。

## 四、命令型（对平级与下属都要小心）

| 原句 | 对方的读法 | 改写 |
| --- | --- | --- |
| 马上做 | 你在命令我 | 这个比较急，能不能今天下班前先给个初版？ |
| 你必须 | 我们不是同事，是上下级 | 这块需要 {X}，你看今天能安排吗？ |
| 现在就给我 | 我不重要，我的事不重要 | 我这边卡住了，能不能先给我 10 分钟？ |
| 我不管，反正要 | 我不讲理 | 时间很紧，我们能砍掉哪部分保上线？ |
| 别再犯这种错 | 你能力不行 | 这次的问题出在 {环节}，下次我们在那里加一道检查 |

**对上级用时**：把「必须」换成「需要」、把陈述换成请示，但**别过度客气**——过度客气在同级看来是讽刺。

## 五、责任稀释型（团队协作的头号杀手）

| 原句 | 对方的读法 | 改写 |
| --- | --- | --- |
| 大家看一下 | 没人会看 | @张三 你看接口部分，@李四 你看数据口径，今天 17:00 前 |
| 相关同学跟进下 | 我不知道是不是我 | 这块目前没有明确 owner，我先认领，需要 {X} 支持 |
| 我们一起努力 | 具体谁做什么？ | 分一下：我做 A（周三），你做 B（周四） |
| 需要产品、研发、设计配合 | 谁牵头？ | 我牵头，需要产品出 {X}、研发出 {Y} |

**规律**：**具名 + 具体 + 时间**，三条齐了责任才落地。

## 六、该换渠道而不是改措辞的四种情况

| 情况 | 为什么不能发文字 | 怎么做 |
| --- | --- | --- |
| 要指出具体某个人的失误 | 文字会留存、会被转发、会被截图 | 当面或语音，且只对当事人 |
| 涉及绩效、薪资、晋升 | 极其敏感，误解成本高 | 当面，且有第三方在场更稳妥 |
| 你正在气头上 | 你写的每个字都会成为证据 | 写完存草稿，30 分钟后再看一遍 |
| 对方刚被公开批评 | 此时任何文字都会被读成追击 | 私下、简短、只谈事 |

## 七、一个通用改写公式

> **事实 + 影响 + 请求 + 时间**

❌ 「这个怎么还没好？我等着用呢。」
✅ 「这个接口现在还没联调（事实），我这边的联调卡着（影响），能不能今天下班前先给个能跑的版本（请求），我明早接着测（时间）。」

四段齐了，语气自然就中性了——**因为对方听到的是信息，不是情绪。**

## 八、三个不该改的地方

不是所有「不好听」都要改：

1. **明确拒绝**：「这个我做不了，因为它需要 {X}，而我没有。」——清楚比客气重要。
2. **指出事实冲突**：「你说的数据和后台不一致，我的口径是 {X}。」——这不是甩锅，这是对齐。
3. **设定边界**：「这个需求今天加不进来，最早下周二。」——比含糊答应更专业。

**别把「保护自己」当成「语气不好」。**
